## Common fixes

Card will not add to Wallet: check that Wallet is set up on the phone, then scan the pass QR code again. A pass needs a recent phone system version.

Stamp did not land: one stamp per day per business, and 60 seconds between stamps. Wait, then try again. For a staff stamp, staff must enter the correct 4 digit staff code. The code is set in Program settings.

Reward is not ready: the card needs 9 stamps by default. The count shows on the Wallet card. A business can change the target when it builds its pass.

Birthday treat did not arrive: the treat lands on the birthday itself. It needs a birthday on the card. Check the date in Program settings.

Data looks wrong: the business can clear demo data from the Analytics screen and restore it from the same screen.

## No login, no ads

No login is needed to use Stampies, and no ads are shown. Support never asks for a password or a staff code by email.

## Response time

Support aims to reply within 2 business days.
